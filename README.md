# Daily Quote

Get inspired with random quotes, save favorites, and share them.

## How to Use

**Step 1:** Open `index.html` in your browser.

**Step 2:** An onboarding tutorial appears on first visit. Click **Get Inspired** (or Skip).

**Step 3:** A random quote appears in a beautiful card. Read and reflect!

**Step 4:** Click **New Quote** to see another random quote.

**Step 5:** Click **Heart** to save a quote to your favorites list.

**Step 6:** Click **Copy** to copy the quote text to clipboard.

**Step 7:** Click **Share** to open a Twitter share window with the quote.

**Step 8:** Scroll down to see and manage your saved favorites.

## Features
- 20 curated inspirational quotes
- Random quote generator
- Save favorites with heart button
- Copy to clipboard
- Share to Twitter
- Delete favorites
- Beautiful card design
- LocalStorage persistence

## Tech
HTML + CSS + JavaScript | Twitter Intent API | Clipboard API
